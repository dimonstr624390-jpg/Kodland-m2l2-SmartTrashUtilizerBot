# Kodland-m2l2-SmartTrashUtilizerBot
О боте:
бот, который определяет разновидность многих эмодзи(не всех).
Комманды, которые он может выполнить:
/start - создание нового сеанса бота или приветствие пользователя
/help - помошь пользователю, если он только зашёл в бота, чтобы быстрее в нём разобраться
/ok - вернуться на шаг обратно к приветствию
/sort - объяснение того, что надо делать пользователю в этом боте
/list - показывает список всех эмодзи, которые может распознать бот
